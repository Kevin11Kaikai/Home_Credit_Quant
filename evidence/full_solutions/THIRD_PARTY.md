# Third-party sources and local-use boundary

- Home Credit 2024 champion: **yuuniee / yuuniekiri**, three public Kaggle inference notebooks and first-place writeup. Original notebook attribution is preserved. License was not exposed by the Kaggle API. A later browser check shows Apache 2.0 for the DenseLight notebook's last successful displayed version (v11), and a private model dataset; see SOURCE_AUDIT_ADDENDUM.json. No redistribution of the private weights or dataset is authorized or attempted.
- Requested fraud workflow: **Kevin11Kaikai/Fraud_Detection_Tabular_Transformer**, commit `d10eb6315319b20d0be7a94e63a4f89c6381d1be`. The published primary method is ExcelFormer with ordered target encoding, mutual-information feature ordering and MI-weighted feature mixing. No fraud data, weights or metrics are imported into this experiment. Repository license is not supplied.
- ExcelFormer: **WhatAShot/ExcelFormer**, commit `17f70526390e70390bb8c8ec3850697eb730f9cd`. Reused cached original `bin/excel_former.py`, `lib/deep.py` and `lib/aug_utils.py`, verified against the cache source manifest. Architecture source differs only in the isolated helper import. The local SDPA attention adapter is tested against the original forward and gradients. Upstream LICENSE lookup previously returned 404; files remain local.
- S6E7: **Masaya Kawamata**, `s6e7-ft-transformer-v2-cv-0-95063`, version 1, SHA-256 in SOURCE_MANIFEST.json. Uses the author's released `masamlp==0.3.0` and `catstat==0.4.0`. The entire 7-fold × 4-member recipe is specified; binary-target and resource adapters are explicit. No student-health records are downloaded.
- DenseLight: official `lightautoml==0.3.8` `DenseLightModel`, imported directly. Its default core is reused, but the unavailable fitted AutoML pipeline is **not** reconstructed exactly; our fold-only scaling/one-hot wrapper is a declared choice.
- LightGBM `4.6.0` and CatBoost `1.2.8` use installed official packages. Python package versions and metadata are recorded in SOURCE_MANIFEST.json and requirements.lock.json.

Existing official Home Credit training cache is reused under the user's already accepted competition access. Row-level records and derived predictions remain local. No package installation modifies the old MVP virtual environment; `.venv_full` uses existing system packages read-only and local pinned overrides. Nothing is uploaded or pushed.
