The first delivery was an implemented, locally tested package with a data-authentication blocker. The real subset is now acquired and audited; current completion is recorded in `runs/homecredit_temporal_v1_20261014/acceptance.json`. No split, feature information, candidate or evaluation rule was changed.

The single engineering smoke preceded some recovery/reporting corrections. Its checkpoints and original code hashes remain preserved. Later tests check the current code, including a synthetic final-evaluation transaction. No extra brief model fitting was performed merely to refresh that smoke. TabM checkpoints include model, optimizer, RNG and minibatch position.

The first pytest invocation encountered a Windows temporary-directory permission error; the tests were moved to an explicit workspace-local temporary root. An old psutil build proved incompatible with Python 3.12, and the isolated environment was repaired to psutil 7.0.0. The official package files for TabM and numerical embeddings are byte-identical to their pinned source snapshots. Dependency consistency was checked after installation. Existing Matplotlib/pyparsing and argparse warnings do not indicate failed tests.
