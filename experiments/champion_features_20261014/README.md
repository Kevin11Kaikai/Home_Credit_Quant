# Matched feature transfer

These are the research adapters, not a directory of distributed data/checkpoints. Current completion and pause state are in [STATUS.json](../../STATUS.json); historical evidence is under [evidence/feature_transfer](../../evidence/feature_transfer/).

Read [REPRODUCE.md](../../REPRODUCE.md) before executing anything. A fresh follow-up requires an authorized dataset, a completed new core run, the specified source dependencies, a compatible isolated environment, and explicitly chosen training commands. `CREDIT_MVP_CORE_RUN` selects that new core directory. It does not relocate or bypass an old freeze manifest. Windows/PowerShell is the tested follow-up platform.

The original ExcelFormer/S6E7 campaign remains paused. Uploading these adapters did not resume it. Absent model artifacts and unresolved source availability remain real reproducibility limits. No source score or partially trained network is presented as a completed Home Credit result.
